# Ajout de Texte à une Vidéo

Ce script Python vous permet d'ajouter du texte à une vidéo à des moments spécifiques. Il prend en charge les fichiers au format .mp4 et utilise la bibliothèque OpenCV pour la manipulation vidéo.

## Installation

### Python 3

Si vous n'avez pas déjà Python 3 installé, vous pouvez le télécharger et l'installer depuis [le site officiel de Python](https://www.python.org/downloads/).

### Dépendances

Installez les dépendances en exécutant la commande suivante dans votre terminal :

```bash
pip install opencv-python
```
